# CS320 - Portfolio Submission

## How can I ensure that my code, program, or software is functional and secure?

I ensure that my software is functional and secure by writing unit tests, validating user input, and following software requirements closely. Testing each component individually helps identify bugs early, while input validation prevents invalid data from causing errors or security issues. I also review my code to improve reliability and maintainability.

## How do I interpret user needs and incorporate them into a program?

I interpret user needs by carefully reviewing the project requirements and identifying the features the user expects. I then design classes, methods, and tests that directly support those requirements. Throughout development, I compare my implementation against the requirements to ensure the program behaves as intended.

## How do I approach designing software?

I approach software design by breaking a problem into smaller, manageable components before writing code. I identify the classes and responsibilities each component should have, then implement and test them individually before integrating everything together. This modular approach makes the software easier to understand, maintain, and expand in the future.
